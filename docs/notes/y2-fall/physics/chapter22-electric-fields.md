反正可以简化成：
$$E=\frac{1}{2\pi\varepsilon_0}\frac{qd}{z^3}$$
而电偶极矩可以定义为：
$$\vec{p}=qd$$
方向由负电荷指向正电荷

## 2. 带电线引起的电场
要注意区分三种电荷密度的标记：
- 线电荷密度$\lambda$
- 面电荷密度$\sigma$
- 体电荷密度$\rho$

<img src="./image/屏幕截图%202021-12-29%20104517.jpg" height=50%>

$$E=\int dEcos\theta=\frac{z\lambda}{4\pi\varepsilon_0(z^2+R^2)^{3/2} }\int_0^{2\pi R}ds\\~\\=\frac{qz}{4\pi \varepsilon_0(z^2+R^2)^{3/2} }$$
离得足够远的时候，电场看起来就是点电荷的电场一样


## 3. 带电圆盘引起的电场
积分一通：
$$E=\frac{\sigma}{2\varepsilon_0}(1-\frac{z}{\sqrt{z^2+R^2} })$$
距离足够远的时候，括号就可以去掉了
