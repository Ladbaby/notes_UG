## What is an algorithm and its property
> An algorithm is composed of a set of steps for solving a specific problem

- **Finiteness** (有限性)

    解题步骤必须有限
- **Definiteness** (已定义行为)

    5/0就是未定义行为
- **Effectiveness** (效率)
- Zero or more inputs and one or more outputs
- **Termination** (有终止)

    OS就不是算法

## Q1: The difference between algorithm and problem
- Algorithm is a group of roles
- A step-by-step procedure for solving a problem or accomplishing some end
- An algorithm solves a problem if it produces an acceptable output on ==every== input

## Q2: The difference between Algorithm and Numerical Analysis
- Numerical Analysis is used to solve some numerical problems

## Q3: The difference between Algorithm and AI
- AI is used to solve all kinds of problems in almost all fields
- Algorithms solve specific computational problems
